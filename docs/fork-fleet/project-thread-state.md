# Orchestrator 线程状态隔离

分支：`codex/fix-project-thread-state`。修复项目对话在替换 Orchestrator 时沿用旧 provider 线程状态，导致新会话误显 `The agent's thread hit an internal error` 或线程关闭提示的问题，集成到 `main-fleet`。

- 项目对话绑定到不同会话所有者时，清空旧线程的状态、等待标记、关闭时间和归档时间。项目历史消息继续沿用原有保留规则。
- 状态清理与新会话绑定在同一数据库事务中提交，返回给新控制器的内存记录同步清空，避免数据库与界面继续沿用不同的线程状态。
- 重新打开或重连同一会话保留 provider 已报告的状态；新线程后续报告真实故障时仍按原流程记录和显示。此修复的范围是替换会话时的状态隔离。

升级无需数据库迁移；状态清理在会话所有者实际更换时触发。上游提供等价实现后，核对替换会话清理旧状态、同一会话重连保留真实状态的行为，再移除此分支补丁。
